# Miau, Muh und Mehr

Offline-first Android and iOS app (Expo / React Native) that plays short animal
videos. The UI is German and the audience is small children. Clips come from YouTube
Shorts that CI downloads, normalizes, and publishes as GitHub Release assets.

## Definition of done

A change is done when all of these pass from the repository root:

```sh
npm run typecheck
npm test
python3 -m unittest discover -s scripts/content -p 'test_*.py'
python3 -m unittest discover -s scripts/android -p 'test_*.py'
```

Run the Python suites only when `scripts/` or `content/` changed, and the npm
checks only when app code changed. When in doubt, run all four — they are fast.
Do not commit `node_modules/`, generated native folders, or `.expo/`.

## Setup

Node.js 24 and Python 3.12+ are required. `scripts/jules-setup.sh` installs
Node 24 through nvm and runs `npm ci`; the Python suites need no dependencies
beyond the standard library.

The app itself cannot be launched in a headless VM — it needs an Android device
or emulator (`npm run android`) or Xcode 26.6 with an iOS Simulator
(`npm run ios`). Verify changes with the checks above when no suitable device is available.

## Layout

- `App.tsx` — the whole UI: tiles, carousel, list, and playback screen.
- `src/library.ts` — catalog and manifest loading, download and update logic.
- `src/playback.ts` — clip selection and shuffling (`src/playback.test.ts`).
- `src/preferences.ts` — persisted user settings.
- `src/types.ts` — shared types.
- `content/catalog.json` — hand-edited source records, the only content file
  edited directly.
- `content/manifest.json` — generated by CI. Never edit it by hand.
- `scripts/content/add_clip.py` — normalizes names, derives ids, appends clips.
- `scripts/content/build_content.py` — yt-dlp and FFmpeg pipeline.
- `scripts/android/configure_signing.py` — release signing for the APK build.
- `.github/workflows/` — `ci.yml` (checks), `content.yml` (publish clips),
  `android.yml` (APK build), `ios.yml` (unsigned iOS Simulator build).

## Conventions

- TypeScript is strict. Tests run on vitest, Python tests on `unittest`.
- Code, comments, commit messages and pull request descriptions are English.
  User-facing strings in the app are German.
- Commit messages must follow Conventional Commits format (e.g. `feat:`, `fix:`, `chore:`, `docs:`, `ci:`) enforced by commitlint (`@commitlint/config-conventional`) so semantic releases work correctly.
- Pin exact dependency versions in `package.json`; no caret ranges.
- Expo SDK packages are upgraded together, not individually.

## Adding an animal clip

Use the script rather than editing `content/catalog.json` by hand — it
normalizes the English name, derives the id, rejects duplicate videos, and keeps
the German sort order:

```sh
python3 scripts/content/add_clip.py \
  --catalog content/catalog.json \
  --animal "guinea pig" \
  --name-de "Meerschweinchen" \
  --url "https://www.youtube.com/shorts/JoNTmi6sfro"
```

`--name-de` is required for a new animal and optional when appending a clip to
an existing one. Pick clips that show the real animal making its own sound; no
memes, AI or cartoon footage, and nothing scary or violent. Confirm a candidate
is public and embeddable before adding it (a 200 means CI can download it):

```sh
curl -s -o /dev/null -w "%{http_code}\n" \
  "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<videoId>&format=json"
```

Pushing `content/catalog.json` to `main` publishes the media and regenerates the
manifest. The fuller walkthrough lives in `.claude/skills/add-animal-clip/SKILL.md`.
